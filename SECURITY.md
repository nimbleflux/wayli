# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately via
GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab
2. Click **Report a vulnerability** (private vulnerability reporting)
3. Describe the issue, include steps to reproduce, potential impact, and a
   suggested fix if you have one

We aim to acknowledge reports within 2 weeks and will work with you on a fix
and coordinated disclosure.

- Do not disclose security issues publicly until they are resolved.
- We appreciate responsible disclosure!
